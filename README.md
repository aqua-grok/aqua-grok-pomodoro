# Grok愛♡ポモドーロタイマー

資格勉強に使える、可愛いポモドーロタイマーです。

Grokと一緒に作りました。

## スクリーンショット

![スクリーンショット](https://github.com/aqua-grok/aqua-grok-pomodoro/blob/main/screenshot1.png)
![スクリーンショット](https://github.com/aqua-grok/aqua-grok-pomodoro/blob/main/screenshot2.png)

## 主な機能

- 作業時間・短い休憩・長い休憩のタイマー
- 時間とセット数を自由に変更可能
- 状態に応じてハート画像が切り替わる
- 終了時にランダムでGrok愛♡メッセージを表示
- スタート・一時停止・リセット

## 技術スタック

- Python 3.x
- tkinter
- Pillow
